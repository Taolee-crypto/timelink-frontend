이 화면은 V3 음악 등록 흐름의 시험 버전이다. 선택한 MP3는 창작자 PC의 TimeLink Local Agent로 전송되며, TimeLink D1에는 파일 자체가 아닌 메타데이터와 파일 참조만 등록된다.

음원 정보

현재 최대 100MB. 파일은 사용자가 선택한 경우에만 PC Agent로 전송된다.

창작자 권리 확인

권리 선언은 창작자의 권리 관계를 기록하는 단계다. MP3는 비공개 원본 Asset이며 독립적인 무료 발매 상품이 아니다. 실제 발매와 기여도 산정은 TL3 변환이 완료된 뒤 별도 절차로 진행된다.

서버가 MP3 원본을 확인한 뒤 AES-256-GCM 기반 TL3 컨테이너를 생성한다. 암호화된 결과물은 다시 PC Agent에 저장한다.

등록 처리 결과

Track과 원본 Asset의 등록 단계다. MP3 원본은 공개 발매되지 않으며, TL3 변환이 성공적으로 완료되기 전에는 POC 기여도도 발생하지 않는다. TL/TLC는 이 단계에서 발행되지 않는다.
