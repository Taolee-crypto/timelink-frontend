음원 정보

현재 최대 500MB. 파일은 사용자가 선택한 경우에만 PC Agent로 전송된다.

창작자 권리 확인

권리 선언은 자동으로 검증 완료 처리되지 않는다. TimeLink의 별도 심사와 확인을 거쳐야 공개 발매가 가능하다.

등록 처리 결과

현재는 심사 요청 단계다. 자동으로 SharePlace에 공개되거나 TL/TLC가 지급되지 않는다.
