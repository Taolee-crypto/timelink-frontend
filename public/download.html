⚙️ 설치 방법
1
위 버튼으로 설치파일 다운로드
Windows: TimeLink-Player-Setup.exe 실행
macOS: TimeLink-Player.dmg 열고 Applications 폴더로 드래그
2
timelink.digital 계정으로 로그인
계정이 없으면 회원가입 후 TL을 충전하세요.
3
공유플레이스에서 TL3 V5 파일 선택
공식 공유플레이스에서 공개된 TL3 V5 자산을 선택하고, 사용할 보호 파일을 다운로드해 주세요.
4
TL3 파일 열기 → ▶ 온라인 재생
파일 확인 후 ▶를 누르면 동일한 서버 자산의 공식 재생 페이지가 열립니다. 브라우저에서 추가 로그인이 필요할 수 있으며, 실제 음원 재생과 TL 정산은 웹에서 진행합니다.
