⚙️ Installation Guide
1
Download the installer using the buttons above
Windows: TimeLink-Player-Setup.exe Run
macOS: TimeLink-Player.dmg Open it and drag the app into your Applications folder
2
timelink.digital Sign in to your account
If you do not have an account, create one and add TL.
3
Download a .tl file from SharePlace
Select the ⬇ .tl button on an asset card to save the encrypted .tl file
4
Double-click the .tl file
TimeLink Player opens automatically, checks your TL balance and starts playback.
