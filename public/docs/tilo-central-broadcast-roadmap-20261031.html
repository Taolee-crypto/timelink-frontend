중앙방송 1차 범위 종료와 향후 개발계획

운영자가 확정한 1차 범위는 음악 방송과 글로벌 메신저입니다. 현재 기능 구현 단계가 모두 기록된 항목만 1차 개발률에 포함하며, 기존 재생/채팅을 임의로 수정하거나 미래 작업을 완료 처리하지 않습니다.

1차 · 현행 확정 범위

기능 구현 기준 100% · 음악 + 메신저

  • 국가별 중앙방송 선택, 공식 TL3 V5 청취, 재생·정지·곡 정보 표시 및 편성 목록
  • 회원 로그인 기반 글로벌 메신저, 접속 회원 표시, 메시지 목록·전송·속도 제한
  • 중앙방송 화면과 기존 관리자 방송 운영 화면 연결

테스트/구현 이력과 실제 전체 단말·장시간 운영검증은 별개입니다. TIME FREE 우선, 미보유 시 일반 청취 1초당 1TL 정책과 매장 상업 이용권도 다른 분야의 개별 정산·권리 검증을 따릅니다.

다음 단계부터의 개발 원칙

현행 방송 보호: 정상 동작하는 TL3 LOVE CODE·재생·곡 편성·메신저 코드를 변경하지 않습니다. 새 기능은 분리된 코드와 검증 환경에서 먼저 검사하고, 운영 관리자 승인과 변경 이력·롤백 가능성을 확보한 뒤 반영합니다.

2-A · 방송 안정성과 관측

예상치 못한 끊김, 국가별 접속 실패, 메시지 오류를 확인할 읽기 전용 상태 모니터링과 진단 로그를 우선 구축합니다.

완료 조건: 비정상 재생·메신저 실패 시각과 원인을 운영자 화면에서 확인, 재현 테스트·복구 정책·기존 UI 회귀 CI 통과. 실제로 수행하지 않은 복구를 완료로 표시하지 않습니다.

2-B · 저작권과 방송 정산의 확정

방송권이 확보된 TL3 V5 음원에 한하여 실제 송출초 증빙을 모으고, 관리자 설정 할인계수 기본 0.3과 권리자 70%·플랫폼 30% 원장 분배를 검증합니다.

완료 조건: 권리 근거, 송출 이벤트, 현지 자정, 원장 멱등성, 재원 마련과 전후 잔액을 대사. 시뮬레이션은 지급 완료로 간주하지 않습니다.

2-C · 24시간 독립 송출

브라우저 연결에 의존하는 재생과 별도로 국가별 서버 주도 24시간 송출과 자동 장애 복구를 개발합니다. 기존 방송을 대체하기 전에 별도 검증을 거칩니다.

완료 조건: 독립 송출의 재현 가능한 실증, 24시간 연속 운영 기록, 브라우저·네트워크 장애 복구, 국가별 날짜 경계와 청취 측정 검증.

2-D · 선택형 AI DJ·현지화

현지 언어와 날씨·시간대에 맞춘 DJ 목소리, 뉴스·멘트, 방송 학습 자료는 별도 선택 기능으로 남깁니다.

완료 조건: 합법적인 자료 사용 권한과 합성 음성 동의, 국가별 품질 검수, 관리자 승인과 안전한 장애 시 원음악 재생 유지. 무허가 DJ 음성 학습과 미확인 뉴스 방송을 금지합니다.

2-E · 메신저 운영 고도화

회원 메시지 신고·제재·스팸 예방·관리자 감사 기록과 다국가 확장성을 별도 과제로 설계합니다.

완료 조건: 개인정보·접근 권한 검증, 신고 처리·제재 복구 감사, 다중 접속 부하 테스트, 메시지 노출 실패 방지.
