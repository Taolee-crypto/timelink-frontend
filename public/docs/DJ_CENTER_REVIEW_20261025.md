# DJ 센터 재점검 및 정상화 — 2026-10-25

DJ 역할은 곡 선택·프로그램 구성·방송 진행이다. 영업과 매장 연결은 대리점이 담당한다.

## 확인된 문제와 수정
- 내 업로드 곡만 조회하던 목록을 공개·봉인·권리 선언 상태의 V5 음원 라이브러리로 연결했다. 내 곡과 홍보곡 필터 및 검색을 제공한다.
- 폐기된 50:50 편성 조건과 무조건 return 하던 저장 중단 코드를 제거했다. 현재 저장된 v5-broadcast-programming-policy.md의 홍보곡 우선·일반곡 보충 정책을 적용했다.
- 곡 선택·선택 해제·방송 순서 변경·전체 곡 수에 맞춘 채우기·세트 저장을 연결했다.
- 세트 저장·시작·다음 곡·현재 곡·모니터 권한이 같은 V5 공개/봉인/권리 선언 조건을 사용한다. 비공개·수익 보류·권리 미신고 음원은 제외한다.
- 서버가 제공한 track_details를 사용해 정상 곡이 '(삭제된 곡)'으로 보이던 문제를 수정했다.
- 무료 개설 정책과 충돌하던 유료 entitlement 차단을 제거했다. 기존 방송 운영 동의는 계속 확인한다. 결제나 지급을 실행하지 않는다.
- 구형 TL3.resolveUrl 호출을 V5 기기·세션 라이선스 플레이어로 교체했다. 무료 모니터는 본인의 활성 방송에서 현재 재생 중인 정확한 곡만 허용하며 수익/송출 증빙을 생성하지 않는다.
- 중복 방송 시작과 방송 중 세트 변경을 방지했다. 곡 종료·다음 곡·자동 진행·종료 시 플레이어 정리를 연결했다.
- DJ 센터에서 스토어 찾기, 카페 지원, 지원 현황, 영업 계약, 중복 온에어 목록 및 해당 화면 전용 호출을 제거했다. 기존 카페/대리점이 사용하는 서버 API 및 계약 데이터는 유지했다.
- 공개 방송에 반영되지 않던 브라우저 전용 스튜디오 꾸미기를 제거했다. 실제 DJ 프로필을 대표 화면과 연결했다.
- API 오류를 '곡 없음'으로 숨기지 않고 원인과 재시도 버튼을 표시한다.
- 관리자 정산 화면의 중복 패널·노출 CSS·중첩 함수 범위·응답 이중 파싱을 수정했다. 정산 원천 검증이 아직 차단된 상태는 서버 메시지로 표시한다.

## 검증
scripts/test-dj-v5-center.cjs: 실제 DJ 라우트 핸들러와 SQLite로 목록·자격 필터·순서·중복 제거·무료 개설·시작 중복 방지·방송 중 편집 차단·다음 곡·공개 철회·종료·삭제·모니터 소유권을 검증한다. 테스트에서 인증 토큰 검증기는 고정 fixture로 대체한다.
scripts/test-dj-center-ui.cjs: 실제 페이지 함수로 검색·필터·선택·순서·홍보곡 우선 보충·저장·V5 모니터 제어·API 실패 노출·영업 화면 제거를 검증한다. 브라우저와 오디오는 fixture로 대체한다.
프로덕션 빌드는 TypeScript 및 기존 통합 검사와 위 검사를 거쳐 배포한다.

## 범위와 남은 검증
실회원 로그인·실제 음원의 청각적 확인은 별도 운영 검증이 필요하다. 카페/인카 청취자의 구형 팝업 및 별도 청구 API, 대리점 영업 시스템 구축, 크리에이터 현금 지급 원천 검증은 이번 DJ 제작 화면 정상화와 별도다. 이번 수정은 청취자 요금·수익 배분·지갑 잔액·기존 계약 데이터를 변경하지 않는다.
