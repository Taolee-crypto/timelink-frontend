# TimeLink 프론트엔드 리뉴얼 구현 기록

2026년 10월 24일 한국 시간. 승인된 기획안에 따라 기존 정적 HTML 파일명과 백엔드 API를 재사용했다. 화면 리뉴얼 완료와 운영 계정의 결제·지급 검증은 구분한다.

## 기획서

- `public/docs/TimeLink_Frontend_Renewal_Plan_20261024.docx`: 작성한 원본 기획서.
- `public/docs/TimeLink_Frontend_Renewal_Plan_20261024.html`: 브라우저 열람본.
- `public/docs/RENEWAL_IMAGE_SOURCES.md`: 실제 사진 10종의 출처와 사용 기준.

## 기존 파일 재사용

- `index.html`: 공통 탐색과 검색, 언어 선택, 로그인 진입 및 재생 영역을 유지하는 화면 틀.
- `sidebar.js`: 홈·둘러보기·방송·내 공간, 활동 공간과 계정 도구. 운영 메뉴는 기존 관리자 API의 승인 이후 노출.
- `main.js`: 기존 페이지 URL의 이동·뒤로가기·곡 재생·TILO 수신 상태를 관리한다.
- `renewal/renewal.css`, `renewal/renewal.js`: 공통 디자인과 기존 페이지 연결. 새 화면 복사본 대신 기존 파일에 적용.
- `dashboard.html`: 사진 중심 홈, 실제 공개 곡과 커버, 최근 본 곡, 카페·인카·방송 진입, 내 공간과 기존 활동 패널.
- `shareplace.html`: 공개 목록과 곡 상세를 연결. 큰 커버 카드와 검색, 장르·정렬 상태의 URL 유지. 비회원은 공개 목록을 탐색하고 인증이 필요한 행동에서 로그인한다.
- `creator.html`: 기존 회원 계정으로 창작·기존 음원 등록. 비회원 진입 안내, 사진 배너, 등록 방식별 사진. 입력 초안은 **계정별 현재 브라우저 저장**이며 파일·권리 동의·금액은 복원하지 않는다. 서버 초안 동기화로 표시하지 않는다.
- `track.html`, `tl3-v5-player.js`: 기존 V5 재생과 과금 경로를 유지. 개인 재생을 별도 프레임에 두어 화면 이동으로 파괴하지 않는다. 최초 재생은 플레이어의 재생 버튼을 직접 누른다. 종료 시 마지막 계량과 종료 정산 응답을 기다린다. 기존 정지 버튼을 눌렀어도 그 종료 작업을 추적한다.
- `radio.html`: 사진 기반 방송실. 기존 국가 선택과 공개 방송 권한을 유지. 수신 프레임은 다른 화면으로 이동해도 유지되며, 개인 곡과 방송을 전환할 때 이전 재생을 먼저 종료한다. 실제 오디오 상태와 연결·대기를 구분한다. 이는 서버 상시 송출의 완성을 의미하지 않는다.
- 기존 지갑·카페·인카·DJ·광고·프로필·관리 화면의 기능 및 파일명을 유지하고 공통 화면 틀과 반응형 스타일을 적용했다.
- `renewal/files.html`, `renewal/music.html`: 실제 파일·음악 관리 기능은 유지하고 내 공간에서 연결한다.

## 중복과 불필요한 항목 정리

- `renewal/shareplace.html`, `shareplace-v3.html`은 같은 `shareplace.html`로 연결하는 최소 호환 파일로 축소했다.
- `wallet-v2.html`은 `wallet.html`로 연결하는 최소 호환 파일로 축소했다.
- 옛 주소의 검색 인자와 해시는 유지한다. 외부 공유 링크를 끊기 위해 주소 파일 자체를 제거하지 않았다.
- `_shared/topbar-v2.js`는 모든 실행 호출자를 제거한 뒤 삭제했다. 이 파일의 비회원 강제 로그인과 별도 메뉴·잔액 표시가 새 공통 화면과 충돌했다.
- 호출이 없던 오타 파일 `mainfest.json`을 삭제하고 실제 `manifest.json`은 유지했다.
- `serve.json`의 없는 카페·차량·온보딩 목적지를 기존 실제 화면으로 바로잡았다.
- 음악 수익·재생 횟수를 Pulse 배수로 추정해 보여주던 내 공간 표시는 제거했다. 확인할 수 없는 통계는 확인 필요 상태로 표시한다.

## 사진 사용

사진 10종과 720px 카드 파생본 10종을 약 2MB의 로컬 JPEG로 저장했다. 홈, 탐색, 창작, 방송, 카페, 차량과 회원 영역에 사용한다. 실제 곡 커버와 회원·채널 사진을 우선한다. 대표 사진을 실제 회원·매장·차량 사진으로 오인하지 않도록 대체 사진에 표시한다. 업로드 사진이 있는 항목을 스톡 사진으로 덮어쓰지 않는다. 커버 로드 실패 시 대표 사진을 사용한다.

- 공통 화면의 출처·프레임 검사, 기존 주소 이동, 재생 프레임 유지, 종료 응답 전 프레임 보존, TILO 프레임 유지 회귀 검사.
- 실제 V5 종료 함수의 마지막 계량 대기·종료 요청 1회·동일 Promise 반환 검사.
- 실제 V5 종료 함수의 정산 실패 보존·성공 콜백 미발생 검사.
- 로컬 리소스 경로, 사진 10종과 파생본·출처, public/docs 기획서 존재 검사.

## 계속 구분해야 하는 사항

운영 계정으로 수행하는 실제 유료 재생·결제·환전·권리자 지급과 24시간 서버 송출은 이번 비회원 시각 검수의 통과 범위가 아니다. 권리 청구·조사·보관금 지급, 창작자 환전율 정책, 미완결 교환풀은 기존 추적 문서의 남은 항목으로 유지한다. 기본 메뉴·신규 안내 문구는 6개 언어를 제공하며 기존 모듈의 모든 문장 번역까지 완료했다고 판정하지 않는다.

브라우저 내 이동은 재생 영역을 유지한다. 브라우저 탭 자체의 종료·새로고침이나 언어 변경은 별도 생명주기이며, 재생 중 언어 변경은 종료 후 진행하도록 안내한다. 서버 응답 없이 브라우저에서 잔액을 임의 가산하거나 정책 수치를 변경하지 않았다.

## 추가 연결 검수

로그인 직후에도 새 토큰의 관리자 권한을 확인해 운영 메뉴를 갱신한다. 캐시된 사용자 역할로 관리자 메뉴를 승인하지 않는다. 기존 확장자 없는 주소를 실제 HTML 파일명으로 정규화한다. 없는 주소가 공통 화면을 다시 불러오는 반복을 막도록 404 화면을 제공한다.

운영 Cloudflare Pages가 `.html` 주소를 확장자 없는 주소로 308 이동시키는 것을 확인했다. 공통 연결 코드가 두 주소를 같은 파일로 정규화하도록 수정하고, 확장자 없는 창작·방송·파일·홈 주소를 회귀 검사에 추가했다. 새 공통 코드와 스타일은 r2 캐시 버전을 사용한다.
