# TimeLink V5 현행 보상·정산 운영 규정 (2026-10-31)

> 이 문서는 2026-10-31에 확인한 사업 결정과 코드 정합성을 기준으로 작성된 현행 규정이다. 과거 2026-10-26 사업·기여도·DJ/광고 운영안은 **역사 기록**이며 현행 지급 근거가 아니다. 운영 설정·법률 검토·권리계약·PG/은행·실서비스 검증이 충족되지 않은 항목은 이 문서만으로 자동 활성화되지 않는다.

## 1. 적용 범위 및 통제
- **활성 보상**: 일반 가입 TL_B, 승인된 충전 TL_B, 검증 추천 보상 TL_B/POC, 실제 음원 이용에 따른 창작자 보상, 별도 검증 TILO 권리자 배분, 운영자가 통제하는 기존 PoC·TLC 채굴 경로.
- **폐기/신규 발행 중단**: 광고 시청 TL_A와 광고주 특별 가입 보너스, 악보·채보 기여 점수, DJ 방송 보너스, DJ/영업매니저 계약·신규 배분, 인카 DJ 선택형 홍보 배분, 일반 MP3 원본의 작품 업로드 보상.
- **역사 보존**: 폐기 전 지급 잔액, 가입·매장 계약 및 원장, 과거 상품·정책 버전은 감사·기존 채무 확인 목적으로 보존하며 삭제·소급 재분류하지 않는다.
- 보상 비율·한도·환금성은 관리자 수동 변경·버전·승인·변경기록을 거친다. 향후 데이터가 쌓이기 전 자동 수익 최적화는 하지 않는다.

## 2. TL 출처와 현금성
- **TL_P**: 검증된 유료 구매분 및 출처가 확인된 적격 현금성 수익. 구매 TL_P는 *모든 적용 법적 환불·선불 잔액 환급권 종료가 증명된 경우* 미사용 구매 lot만 관리자 승인 절차에 따라 TL_B로 이동한다. 임의 7일 경과만으로 자동 변환하지 않는다. 창작자 현금 재원 수익은 구매 lot 전환 대상에서 제외.
- **TL_A**: 광고 서비스 종료. 역사적 잔액은 보존하고 신규 광고 TL_A는 만들지 않는다.
- **TL_B**: 가입·충전·추천 선물 및 플랫폼 부담 사용의 비환금성 자산. TL_B 사용에 따른 창작자 보상을 TL_A 또는 TL_P로 임의 변경하지 않는다.
- TL↔TLC 교환은 기존 자산의 교환, TLC 채굴은 검증된 별도 신규 발행이다. 동일 거래의 사용·환전·교환 이중 처리를 금지한다.
- TL 일반 표시 단위는 정수이고 이중분개 원장 내부는 1TL=10,000 atoms다. 각 수익 배분의 정수 잔여는 정책에 맞는 별도 적립·정산을 한다.

## 3. 음악과 TIME FREE
- 검증된 일반 유료 음악 이용의 기준은 실제 재생 초당 1TL. 해당 음악 사용분 중 **권리자 70%, 플랫폼 30%**를 원천별로 정산한다. 유료 TL_P 사용분은 유료 재원에서 지급할 창작자 정산금으로 처리하고, 무상 TL_B 사용분은 비환금성 TL_B로 지급하며 자동 현금성 전환을 금지한다.
- TIME FREE 이용권은 별도 시간 잔액이다. 시간권 범위 내 재생은 TL 재지급·차감을 하지 않고, 정상 청취에 따른 검증 기여만 인정할 수 있다. 동일 초를 시간권과 TL 과금으로 중복 차감하지 않는다.
- TILO 중앙방송은 **실제 방송 재생 초 × 0.3TL**, 그 배분은 권리자 70% / 플랫폼 30%. 재원 부담자는 플랫폼이며 개인 청취자나 매장 수별로 같은 송출을 반복 청구하지 않는다. 국가별 확정 정산 시점과 실제 송출 증거를 원장에 연결한다. 플랫폼 부담 및 플랫폼 내부 30%를 별도 외부 매출로 중복 계상하지 않는다.
- 공동 권리자 배분·공연권료·국가별 계약은 권리검증과 별도 계약에 따르며, 확인되지 않은 권리자 몫은 보류한다. 창작자 환전 자격은 일반 청취자의 구매 이력 50% 조건과 구분하고 검증 기여도·법적 지급 자격·확보 재원으로 심사한다.

## 4. 기여·TLC 채굴
- 현행 운영 규칙은 관리자 수동 `/api/admin/reward-policy` 설정이며 폐기된 악보/광고/MP3 점수키를 받아 새로 발행하지 않는다.
- 현재 남은 레거시 PoC 평가 영역의 기본 가중치는 재생 40%, 소비 30%, 청취 20%, 보호 TL3 업로드 10%(합계 100%). 테스트·자기 재생·허위 활동·중복 업로드·환불 거래를 제외하도록 실제 검증 생산자 연결이 선행돼야 한다.
- TLC 채굴은 현행 기존 서버 경로와 개발 단계 설정에서만 판단한다. 별도의 TL-1~TL-24 상품별 채굴 초안·100점 신규 기여도 초안은 활성 채굴식에 **동시 적용하지 않는다**.
- TLC 총 채굴원장의 기존 50% 회원 / 50% 그룹 잠금 준비금 분리는 총발행을 늘리지 않는다. 금 보관 준비금의 실제 확보나 TLC 현금가치는 별도 검증 전 보장하지 않는다.
- 교환풀과 채굴이 서로 독립 원장을 갖고, 이중 신규발행·이중 보상·임의 환금성 상승을 금지한다.

## 5. 상점·생활소비
- 나의 카페는 **중앙 TILO 방송 또는 상점주가 직접 선택한 음악 재생** 두 방식. 해당 음악 이용에 필요한 시간 상품·공개재생 권한과 결제는 각각 검증한다. 폐기된 DJ/영업매니저의 신규 배분·DJ 선택형 상품은 재활성화하지 않는다.
- TLMALL 고객 보상 TL의 부담 재원은 실물 주문의 검증된 이익/약정에 근거한다. 한 주문에서 TL 사용은 **10,000원 상당 및 상품금액 50% 중 작은 금액**, 그리고 잔액을 넘을 수 없다. 국제 환산율·현금화 여부·환불 역분개는 국가별 승인 계약에 따른다.
- 공유플레이스 시간 구매는 1초=1TL 기준 명목 시간권과 무작위 할인(별도의 두 추첨)을 구분한다. 할인은 결제금액만 변경하고 구매 시간권의 원래 초/명목 TL_B를 임의 감액하지 않는다. 할인 규칙·실결제·환불 정합성을 통과한 상품만 판매한다.

## 6. 운영·준비금·완료의 조건
- **반드시 검증**: 실제 결제 공급자 확인, 지급·환불 역분개, 권리자 70/30, 현금과 비환금 출처 격리, 자금 준비금, 동시성/멱등성, 국가별 환급권·세금, 관리자 감사, 이용자 고지, 실운영 재생·은행 지급과 원장 대사.
- 원장·지갑의 잔액을 먼저 변경하고 뒤늦게 증빙을 붙이는 처리는 금지. 오류·미검증 이력은 장부에서 조용히 상계하지 않고 보류·심사한다.
- 위 문서는 법률·회계 의견을 대체하지 않는다. 코드 정적/자동 테스트 통과와 운영 계정의 실제 결제·환불·정산 완료는 **별도로** 표시한다.
