# 상세 화면 리뉴얼 · 2026-10-27

사용자의 전체 디자인 현대화·세련미·사용성 개선 지시에 따라 PR #363의 공통 화면에 이어 상세 화면을 정리한다. 기존 API와 재생·권리·청취시간·정산 처리를 유지한다.

## 공유플레이스·트랙

관련 화면과 관리 메뉴로 이어지는 작은 탐색 줄을 제공하고 TIME FREE 상태를 기존 상태 API로 조회한다. 상태 조회가 재생 허가나 TL 과금 규칙을 대신하지 않는다. 곡별 TL 가격은 별도 이용 기준으로 표시하고 시간 이용권을 TL 잔액으로 표시하지 않는다.

공유플레이스의 검색·필터·목록 가독성과 모바일 배치를 정리한다. 트랙은 커버·메타정보·재생 버튼·가사·저작권·댓글의 위계를 정리하고 커버 미등록/조회 실패 시 대표 이미지를 사용한다. 가사 가운데 정렬과 기존 서체는 유지한다. 아이콘 버튼의 이름과 대화상자 초점·Tab 순환·Escape 닫기·원래 버튼으로 초점 복귀를 보완한다. 같은 오디오 컨트롤러와 종료 정산 경로를 사용하며 주기적인 타이머나 오디오 노드를 추가하지 않는다.

## 창작·방송

기존 입력 단계·검사·권리 확인·등록 버튼과 검증 동작을 유지한다. 창작 화면은 단계 표시, 입력 그룹, 파일 선택, 검색 결과, 권리 선언 영역의 간격을 정리하고 고유 ID가 있는 입력의 label 연결과 파일 선택 영역의 키보드 동작을 보완한다. 방송은 국가 선택·실제 방송 상태·회원/채팅 영역의 크기와 간격을 맞춘다. 방송 연결과 청취 권한은 기존 코드에서 판단한다.

## 지갑의 기존 표시와 변경

이전 `wallet.html`에는 고정 TL↔TLC 환율, 예시 TON 주소와 출금 계산, 골드 등급·예시 수익·과거 예시 거래내역이 들어 있었다. 일부 교환·출금 버튼은 서버 처리와 연결되지 않은 표시였다. 이 예시 화면을 실제 계정 데이터 조회 화면으로 바꾼다.

| 표시/동작 | 유지 또는 연결 경로 |
|---|---|
| TL_P·TL_A·TL_B·총 TL·TLC | 기존 `GET /api/eco/wallet` 응답 |
| TIME FREE | 기존 `GET /api/payment/v5/shareplace-time/status` 응답 |
| 원장 이용 기록 | 기존 `GET /api/v3/economy/history?limit=50&offset=…` 응답, 이전 기록 더 보기 |
| TL 충전 | 기존 `/shareplace.html#charge` |
| TL·TLC 교환 | 기존 `/tl-tlc-pool.html` |
| 기존 환전 신청 | 기존 `/dashboard.html?tab=wallet` |
| TLC 채굴/기여 현황 | 기존 `/dashboard.html?tab=mining`의 기존 계산·채굴 처리 |
| 정산 | 기존 `/dashboard.html?tab=settlement` |

서버 잔액이 없거나 조회에 실패하면 `—` 또는 조회 필요 상태를 표시한다. 예시 잔액·환율·현금 상당액을 만들지 않는다. 원장 단위는 기존 서버 코드의 TL 10,000 atoms, TLC 10⁹ atoms 기준으로 표시하며 거래 설명은 텍스트로 처리한다. 이전 지갑의 사용 가능한 충전·채굴·환전 경로는 위 목적지에서 계속 접근할 수 있다. 새 금융 거래나 새 환전 기준은 구현하지 않는다.

## 검증

실제 HTML·스크립트를 Chrome에서 불러 기존 API 계약의 격리된 응답으로 지갑 값/단위, 50건 이후 내역, 조회 실패 시 이전 잔액 제거, 금액 변경 요청 미발생, 트랙 가사·대화상자 초점, 창작 파일 선택, 국가 선택, 다섯 상세 화면의 모바일 가로 넘침을 검사한다. 기존 네 대문·메뉴·호스트·로그아웃·재생 프레임·종료 정산 검사도 실행한다. 실제 계정의 현금 결제나 가청 품질을 새로 확인했다고 판정하지 않는다.
