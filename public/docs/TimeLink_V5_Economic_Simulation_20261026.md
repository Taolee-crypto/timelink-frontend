# TimeLink V5 과금·보상·광고·TLMALL·교환풀 시뮬레이션
기준일: 2026-10-26
상태: 사용자 최신 정책에 따른 계산 실험. 실제 요금·계약·운영 설정·회원 잔액을 변경하지 않았다. 시험 물량·가격·마진이며 사업 예측 또는 시장 단가가 아니다.

## 1. 이번에 바로잡은 기준
1. 소비자의 음원 구매대금70%는 창작자 몫이다. 결제비·플랫폼 운영비·다른 참여자 보상으로 이70%를 삭감하지 않는다. 같은 재원에 플랫폼 몫을 다시 창작자에게 배분하지 않는다.
2. 실제 상품 소비 보상은 TL_P이며 현금 환전과 실물 소비가 가능하다.
3. TL_A·TL_B는 내부 온라인 디지털 상품 소비용이다. 직접 현금 환전과 별개로 검증 기여도에 따라 교환풀에서 일정량을 TLC로 교환할 수 있다. 이전의 ‘어떠한 교환도 불가’ 해석은 이 정책으로 대체한다.
4. TL_P도 TLC 교환풀에서 교환 가능하다. 거래 상대방·기존 물량에 의해 체결하며 신규 발행과 혼동하지 않는다.
5. 최신 발언의 ‘TL 채굴’은 기존 논의에 따라 우선 TLC 신규 채굴로 가정했다. TL 자체의 추가 채굴을 의미한다면 별도 발행 종류와 재원 모형을 정해야 한다.
6. 기여도와 검증 기여자 수가 채굴량·난이도에 영향을 준다. 신규 계정 숫자만으로 난이도를 조작하게 만들지 않는다.
7. TLMALL은 공급 유통업체 입점형 온라인 몰이다. 플랫폼 수익은 유통마진이며 총상품거래액과 구분한다.
8. 위 사항은 과금·보상 통합문서의 상충하는 구절보다 우선한다. 과거 TILO 자체 부담 예산의 규칙을 일반 음원 구매70%에서 공제하는 근거로 쓰지 않는다.

## 2. 납품물과 재계산
수식이 있는 Excel의 설정 E4에서1~4를 선택하면 같은 월손익·교환풀 모형을 다시 계산한다. F:I의 입력은 각 시나리오 시험값, E는 현재 적용값이다.
시트: 결과 / 설정 / 월손익 / 교환풀 / 광고상품 / 상품마진 / 검증 / 기준.
시나리오 비교표는2026-10-26 동일 모형을 차례로 재계산한 실행 결과다. Excel 안에 병렬 시나리오별 다른 모형이나 고정 스냅샷을 숨기지 않았다.
같은 폴더 JSON에는 입력·광고 상품·실행 결과·경계조건 검증을 저장한다. JSON은 저장 시점의 결과이며 Excel 입력을 바꿨다고 자동 갱신되지는 않는다.
개별 자산 이벤트·동시성·은행 송금·실시간 주문 체결 엔진은 구현하지 않았다.

## 5. TLMALL 보상 산식
G=공급업체 정산 후 확보한 유통마진.
C=해당 거래에서 플랫폼이 부담하는 결제·운영·반품 등 비용.이번신규보상제외.
희망 적립률=r.보상배정비율=b.
마진이감당할적립률=max(0,유통마진율-플랫폼거래비용률)×b.
시험 적용 적립률=min(r,마진이감당할적립률).
신규 TL_P보상 비용=순상품거래액×시험적용적립률.
이는 이미회원에게약속한보상을사후삭감하는규칙이아니다.계약·광고게시전에상품별적립률을확정하기위한사전산정안이다.
상품100,000원·거래비용3%·희망적립3%·보상전이익배정30% 가정:
| 유통마진율 | 보상 적용률 | 신규보상비 | 플랫폼잔여 |
| --- | ---: | ---: | ---: |
| 5% | 0.6% | 600원 | 1,400원 |
| 8% | 1.5% | 1,500원 | 3,500원 |
| 10% | 2.1% | 2,100원 | 4,900원 |
| 15% | 3.0% | 3,000원 | 9,000원 |
| 20% | 3.0% | 3,000원 | 14,000원 |
몰이익과신규보상은거래확정/반품을반영한순액으로본다.현금환전가능TL_P는최대약정이행부담으로재원을확보한다.
기존TL_P의상품재사용을신규외부현금매출로중복계산하지않는다.사용시기존보호재원을정산에사용한다.추가적립은추가확보마진과계약을확인한다.
기존 구매당1만원상당·상품가격50%TL사용한도는개별주문결제단계의규칙이다.이번월간모형은적격한주문들에서집계한사용량을가정하며주문별한도실행엔진은포함하지않는다.

## 6. 기여·채굴·A/B교환
검증기여자=활동회원×기준충족비중.최소점수10점은제안이다.
난이도계수=min(1,기준기여자수/현재검증기여자수).
신규채굴량=min(기준월수량×난이도계수,양의채굴전이익×예산비율/TLC당평가부담).
자격미달또는기여자0이면신규채굴0.평가부담은예산산정값이며TLC시가·현금상환가격이아니다.
| 최근기여점수하한 | A/B월교환허용률 제안 |
| --- | ---: |
| 0 | 0% |
| 10 | 1% |
| 20 | 3% |
| 40 | 5% |
| 60 | 8% |
| 80 | 10% |
개별실제사용자는보유량·이미체결한월량·기여확정값으로한도를판정해야한다.Excel은평균기여점수와자격비중의집계근사다.
A/B를받겠다는TLC제공자주문이있을때체결한다.수취자도원래포인트제한을승계한다.A/B를자동TL_P로승격시키는경로는모형에없다.
A/B를다른재원으로보전해TL_P를지급하는별도지원방식을도입하려면부담예산·최대량·제공자를명시해야한다.현정책의확정구현방식이라고가정하지않는다.
풀견적TL_P/TLC와A/B/TLC는다르게설정해제한포인트를받는조건을반영한다.모형은견적하락·요청증가·공급감소시미체결수량을표시한다.같은대가로확정체결될것을보장하지않는다.
수수료는수취자산으로남기고현금매출로더하지않는다.풀참가자의TL_P수취는전체TL_P의무가소멸한것이아니다.

## 7. 4개시나리오 실행결과
원화환산,부가세제외,법인세전·운전자금변동제외의관리모형이다.시장성이나순현금이익을확정한값이아니다.
기본첫달:6개국활동회원합계10,000명,음악구매10%×5,000원,유료스토어100개×50,000원,몰구매30%×50,000원,몰마진15%·거래비용3%·적립3%.고정운영비1,500만원·회원당변동비100원등을반영했다.

기본안에서도12개월차에풀이부족하다.회원활동과요청은성장하지만외부TLC공급가정은고정이고채굴은기여자증가로느려지기때문이다.필연적시장결과가아니라시험입력의결과다.필요한수취자산·매도자수요·유동성인센티브를검증해야한다.
교환급증안은영업조건이기본과동일해모형이익은같지만견적과요청비중·공급가정의변경으로미체결이커진다.영업이익과교환가능성을따로관리해야한다.
낮은마진안은적립상한을낮춰도사업전체고정비를충당하지못한다.낮은매출/마진을토큰공급으로해결한것처럼표시하지않는다.
성장률·회원규모·광고판매를가정한12개월수치는성장예측이아니다.

## 8. 검산과한계
- 동일모형4개시나리오×12개월을재계산했다.
