# TimeLink V5 6대 수익원 과금·보상 시뮬레이션
기준일: 2026-10-26 / 최신 사용자 설명 반영
상태: 운영 전 계산 실험. 실제 요금·계약·지갑·과금 설정 변경 없음.

## 1. 사용자 지정 6대 수익원
| 수익원 | 기준 | 모형에서 분리하는 금액 |
| --- | --- | --- |
| 음원 공유 중개 | 다양한 충전·거래금액의30% | 원거래 총액 / 창작자70% / 플랫폼30% |
| 음원 홍보 | 홍보비의50% | 홍보비 총액 / 플랫폼50% / 별도 집행 몫 |
| 스토어 TL 충전 | 실제 스토어 충전 매출 | 충전 현금유입 / 이용확정 / 기존 파트너 약정 / 미사용 보호잔액 |
| 영업 매니저 | 가입비 + 매출 향상에 따른 일부 회수 | 가입자 수·가입비 / 초기 지원비 / 회수 기준액·회수율 |
| 광고 | 인카 위치기반 / 플랫폼 / 중앙방송 중간 음성광고 | 상품별 판매대금 / 집행비 / 해당 보상 |
| TLMALL 중개 | 약 최소15% 중개수수료 목표 | 상품 거래액 / 공급업체 정산 / 플랫폼 마진 / 플랫폼 거래비 / TL_P 보상 |

음원 공유 수수료를 모든 서비스 매출에 일괄 적용하지 않는다. 음원 홍보50%는 광고 전체에 적용하는 규칙이 아니다.
음원 공유의 충전 시 수수료 확정인지 실제 이용 시 확정인지 최종 약정 확인이 필요하다. 모형은 해당 월 수수료 산정이 확정된 거래액을 입력한다고 가정한다. 평균 금액을 사용하며 모든 충전에 같은 금액을 요구하지 않는다.
스토어 충전은 현금 유입원이다. 미사용분은 사용 가능 잔액으로 남으므로 충전 전체가 즉시 자유로운 이익이라고 해석하지 않는다. 기존 유료 서비스50% 파트너 배분은 실제 이용확정분에서 별도로 계산한다.
매니저 매출 회수의 구간·기준·율은 아직 미정이므로0에서 시작한다. 창작자70%에서 공제하는 것으로 해석하지 않는다.
TLMALL15%는 사용자 사업 기준이다. 공급업체 계약 체결을 검증한 시장 실적이 아니다. 8%인 낮은 마진 시나리오는 이 기준에 못 미치는 조건에서 어떤 문제가 생기는지 보는 스트레스 시험이다.

## 2. 최신 보상·교환 원칙
- 소비자 음원 구매대금70%는 창작자 몫으로 고정한다. 결제비·광고보상·플랫폼 운영비로 이 몫을 깎지 않는다.
- 실제 상품 소비 보상은 TL_P이며 현금 환전·실물 소비가 가능하다.
- TL_A·TL_B는 내부 온라인 디지털 상품 소비용이다. 직접 현금 환전과 별개로 검증된 기여도에 따라 교환풀에서 일정량 TLC 교환이 가능하다. 이전의 모든 교환 금지 해석을 수정한다.
- TL_P는 TLC 교환풀에 참여할 수 있다.
- 신규 채굴량은 기여도와 검증 기여자 수의 영향을 받는다. 최신 발언의 ‘TL 채굴’은 앞선 맥락에 따라 TLC 신규 채굴로 가정했다. TL 자체 신규 발행이면 별도 확인·모형이 필요하다.
- TILO 자체 플랫폼 부담 방송은 별도 예산이며 소비자의 유료 음원 구매와 구분한다. 내부30% 배분을 외부 매출로 새로 계산하지 않는다.
- 운영 초기 모든 보상·과금 변경은 관리자 수동 승인, 정책 버전·효력일·변경 이력으로 관리한다.

## 3. 광고·홍보 상품 시험 입력
가격과 물량은 시장 단가·실제 계약이 아닌 시험값이다.
| 상품 | 시험 단가 | 시작 월 수량 | 보상·배분 |
| --- | ---: | ---: | --- |
| 플랫폼 화면 노출 | 5,000원/검증1,000회 | 100,000회 | 사용자 직접 보상0 |
| 플랫폼 보상형 광고 | 50원/완료시청 | 10,000회 | 완료1회10TL_A |
| 인카 위치기반 클릭 | 200원/유효클릭 | 1,000회 | 클릭 유도 보상0 |
| 인카 위치기반 성과 | 5,000원/확정성과 | 100건 | 취소·중복 제외 |
| 중앙방송 중간 음성 | 10,000원/유효청취1,000회 | 100,000회 | 운영비15% 가정 |
| 음원 홍보 | 1원/검증홍보초 | 300,000초 | 플랫폼50%, 집행 운영비 별도 |

일반 광고 합계에는 앞의5개만 합산하고 음원 홍보는6대 수익원 중 독립 항목으로 계산한다.
모든 상품의 과금 사건·실제 수행·예산 잔액·유효 기간·중복 제거를 확인해야 한다. 같은 캠페인 사건에 CPM+CPC+CPA를 자동 중복 부과하지 않는다.
무효 트래픽·중복·광고 예산 부족·미수행·취소 성과의 과금과 보상을 함께 정정한다. 위 수량은 이미 검증되고 예산 안에서 집행된 물량을 가정하며 실제 광고 엔진 구현이 아니다.

## 4. TLMALL 마진별 TL_P 적립
보상 전 거래 이익 = 확보 중개수수료 - 플랫폼 부담 결제·운영·반품 비용.
시험 적립률 = min(희망 적립률, max(0,중개수수료율-거래비용률)×보상 배정률).
회원에게 약속하기 전에 상품별 적립률을 정하기 위한 산식이며 이미 약속한 보상을 사후 삭감하는 규칙이 아니다.
상품10만원·플랫폼 거래비3%·희망적립3%·보상배정30% 가정:
| 중개수수료 | 적용 적립 | 보상 비용 | 플랫폼 잔여 |
| --- | ---: | ---: | ---: |
| 5% | 0.6% | 600원 | 1,400원 |
| 8% | 1.5% | 1,500원 | 3,500원 |
| 10% | 2.1% | 2,100원 | 4,900원 |
| 15% | 3.0% | 3,000원 | 9,000원 |
| 20% | 3.0% | 3,000원 | 14,000원 |

낮은 수수료 행은 스트레스 시험이며 실제 입점 계약을15% 미만으로 허용한다는 확정 정책이 아니다.
모형에서는 TL_P 발행 시 최대 약정 이행 부담으로 보상 비용·보호 재원을 확보한다. 이후 환전·실물·음악 사용은 그 재원으로 처리해 같은 보상비를 두 번 빼지 않는다.
기존 TL_P의 상품 재사용은 신규 외부 현금 유입이 아니다. 추가 적립은 추가 확보 마진과 계약을 확인한다.
주문별 최대1만원 상당·상품가격50% TL사용 한도는 개별 주문 단계에 적용한다. 월 집계 모형은 적격 주문의 합계를 가정한다.

## 5. 기여·채굴·교환풀
검증 기여자 = 활동회원×자격 충족 비중.
난이도 계수 = min(1,기준 기여자 수/현재 검증 기여자 수).
신규 TLC 채굴 = min(기준 월 상한×난이도 계수, 양의 채굴 전 모형 이익×채굴 예산비율/TLC당 평가 부담).
기여 미달 또는 기여자0이면 신규 채굴0. 내부 예산 평가액은 TLC시장가격이나 현금 상환 가격이 아니다.
A/B 교환 허용률 제안:
| 최근 기여점수 하한 | 월 교환 허용률 |
| --- | ---: |
| 0 | 0% |
| 10 | 1% |
| 20 | 3% |
| 40 | 5% |
| 60 | 8% |
| 80 | 10% |

이 구간은 최종 확정이 아니다. 개별 회원은 실제 잔액·확정 기여·이미 체결한 월 한도로 심사해야 한다. Excel은 평균점수·자격비중의 집계 근사다.
A/B→TLC는 해당 제한 포인트를 받겠다는 기존 TLC 보유자의 주문과 제공 물량이 있어야 체결한다. 수취자에게도 원래 제한을 보존한다. A/B를 자동 현금성TL_P로 바꾸는 보조금은 가정하지 않았다. 다른 유동성 지원 방식을 택하면 지원 재원·단가·한도를 추가해야 한다.
TL_P 풀 거래는 자산 소유자 변경이므로 전체 TL_P 지급 의무를 소멸시키지 않는다. 신규 TLC 발행도 아니다. 수수료는 받은 자산 그대로 보관해 현금 매출에 중복 합산하지 않는다.
미체결 수량은 월 시험 견적에서 요청-체결한 수량이며 누적 확정 채무나 보장된 주문 잔고가 아니다.

## 6. 4개 시나리오 재계산 결과
기본 첫달: 활동회원10,000명, 유료스토어100개, 음악 거래500만원, 스토어충전500만원(당월전액이용 가정), 음원홍보30만원, 몰 거래1.5억원·중개15%, 신규매니저5명×가입비10만원(금액은 시험값), 매니저매출회수0. 광고 물량은 위 표 기준.
‘플랫폼 귀속 수익’은 음악30%·홍보50%·스토어 파트너 배분 차감 후·매니저 수익·광고·몰 마진을 합친 관리회계상 수익 기반이다. 법정 총액/순액 매출 표시는 별도 판단 대상이다.
| 시나리오 | 첫달 플랫폼 귀속 수익 | 첫달 보상·채굴 후 모형 이익 | 몰 적립률 | 첫달 미체결 TLC | 12개월차 미체결 TLC |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기본 운영 | 29,850,000원 | 2,998,112원 | 3.0% | 0.0 | 13046.5 |
| 낮은 마진 | 19,350,000원 | -6,838,888원 | 1.2% | 0.0 | 4930.9 |
| 참여 확대 | 67,200,000원 | 23,311,112원 | 3.0% | 0.0 | 51250.9 |
| 교환 급증 | 29,850,000원 | 2,998,112원 | 3.0% | 85208.8 | 507208.0 |

모든 값은 가정의 결과다. 기본안도 월별 거래가 늘고 TLC공급 가정은 제한돼12개월차 풀 부족이 나타난다. 영업이익이 나는 것과 교환 상대 물량이 충분한 것은 별도로 검증해야 한다.
낮은 마진안은 적립률을 조절해도 고정비를 충당하지 못한다. 광고 수익·홍보·가입비도 포함한 계산이다.
교환 급증안은 영업조건이 같아 모형 이익은 동일하지만 교환 견적·요청 비중·공급 변화로 미체결 수량이 커진다. 시장가격 하락 불가 또는 무제한 환전을 뜻하지 않는다.

## 7. 사용·검증
Excel 설정 E4에서1기본/2낮은마진/3참여확대/4교환급증을 선택한다. F:I 입력을 바꾸면 동일 모형을 재계산한다. 수익원별 금액은 결과 시트 하단에 따로 표시한다.
8개 시트: 결과,설정,월손익,교환풀,광고상품,상품마진,검증,기준.
입력JSON과 결과JSON은 저장 시점 자료이며 Excel을 바꿨다고 JSON까지 자동 갱신되지는 않는다.
독립 숫자 계산 및 잔액·배분 대조452개 통과. 4시나리오×12개월 재계산,6경계조건(기여0/풀0/마진0/견적손익분리/선택입력누락/미선택입력누락) 확인. 계산엔진 수식오류0.8개 시트 주요구간 렌더링 확인.
MicrosoftExcel 별도 실행 재계산은 검증하지 않았다.
6개국 회원 합계에 원화환산 공통단가를 사용한다. 실제 현지 가격·환율·세금·권리계약·은행지급·국가별 자금보호·재고/반품·광고사건 검증·개별 회원 풀 한도 엔진은 별도 구현·자료가 필요하다.
성장률·물량·고정비·제공비·초기 잔액은 실적이 아닌 시험값이다. 초기 판촉/손실 예산을 넣으려면 별도 승인해 보호자금과 구분한다.

## 8. 미확정 변수
매니저 가입비 확정액·매출 회수 기준/구간/율, 스토어 충전과 이용료의 과금 확정 시점·가격, 상품별 실제 중개수수료·이행 책임, 광고 최종 단가·집행/보상 조건, TL_P환전율·시기, A/B풀 교환자격·한도·수취자 조건, TLC기여별 발행표는 추가로 정해야 한다.
