# V5 어드민 영업·매출·재무·정산 구현

2026-10-26. 이 문서는 아래 구현의 범위와 운영 적용 순서를 설명한다.

## 어드민 경로

어드민 사이드바의 ‘영업관리’ 아래에 영업 현황, 영업 매니저, 파트너 DJ, 스토어, 매출·원거래, 배분·정산, 세금·증빙, 가입 심사·영업 정책을 제공한다. 국가·매니저·DJ·스토어·월·검색 필터로 거래를 찾고, 스토어에서 원거래와 배분, 정산서, 실제 원화 전표를 따라 이동한다. 이전 카페 관리 진입은 이 스토어 관리로 연결한다.

## 구현한 동작

- 관리자 전용 /api/sales/admin/finance 및 원거래·정산 상세 API로 기존 매장·담당자·V5 경제원장·원화 회계를 조회한다.
- 무료·광고·보너스 TL 사용에는 새 매니저·DJ 보수를 생성하지 않고, 유료 원거래의 확인된 배분만 정산 대상으로 삼는다. 과거 거래는 덮어쓰지 않는다.
- 정산서 생성은 수취인 세무 분류와 계약·원화 평가·본인계좌·과세시기 확인을 요구한다. 금액을 TL 수량과 동일한 원화 금액으로 자동 가정하지 않는다.
- 해당 보수 TL_P를 예약 계정으로 옮기고 역할별 비용·미지급금 원화 전표를 같은 데이터베이스 트랜잭션 안에 기록한다. 동일 원거래의 동일 역할을 중복 정산하지 않는다.
- 검토 승인 후 실제 은행 지급 증빙을 확인해 지급 기록을 기표한다. 은행 송금을 자동 실행하는 기능은 아니다. TL 예약 정리, 미지급금 감소, 은행·국세·지방세 기록이 함께 처리된다.
- 지급 전 취소는 예약 TL을 반환하고 원화 의무를 역방향 기록한다. 지급 완료 건의 직접 취소와 전용 전표의 일반 역분개는 차단한다.
- 세금 신고·소득자료 제출은 접수 증빙을 연결한다. 국세·지방세 납부 증빙은 기존 재무의 실제 납부 전표와 연결하고 동일 납부액을 초과해 배정하지 않는다. 자동 신고·납부로 표시하지 않는다.
- 정산 상태·세금 프로필 버전 변경, 장부 마감, 잔액 부족, 중복 지급 증빙은 서버에서 확인한다. 세무 미분류·저작자 기타소득·비거주자는 이 국내 파트너 정산 경로에서 보류한다.
- 매니저·DJ 미지급금을 재무의 보호 필요 자금과 가용 현금 계산에 포함한다. 원화 재무 카드는 한국 법인 전체이며 스토어 필터가 적용된 숫자처럼 표시하지 않는다.
- 거래 목록 상한에 도달하면 일부 조회임을 표시하고 연결 실패 시 기존 금액을 그대로 남기지 않는다.

## 확인된 제한

과세 사업자·개인 인적용역·일시적 용역·법인 분류는 계약 실질을 검토한 관리자 입력에 따른다. 해외 정산·환율·조약과 이미 지급한 건의 사후 세무 정정은 별도 검토한다. 공급가액·부가세 포함 여부와 현금 지급 자격·원화 평가액은 운영 계약 근거를 입력해야 한다. 미확정 정책을 자동 확정하지 않는다. 부가세 매입세액 공제는 적격 증빙 검토 없이 자동 적용하지 않는다.

가입 선물 총 100,000TL, 고객 소비 1% TL_P 지급, 상점주 PoC 채굴 개시 기준 전체 구현을 이 어드민 정산 변경에 포함한 것으로 해석하지 않는다. 해당 정책·기능은 각각 기존 정책 문서와 실제 구현 상태를 확인한다.

## 배포 순서

1. 백엔드 변경을 먼저 병합한다. 배포 워크플로가 기존 한국 회계 스키마 다음에 sales_finance 마이그레이션을 준비한다. 마이그레이션은 새 테이블·계정·인덱스·보호 트리거를 추가하며 기존 잔액·정산을 자동 생성하지 않는다.
2. 백엔드 배포 및 관리자 조회 API 준비를 확인한 뒤 프론트엔드를 병합한다.
3. 실제 관리자 계정에서 조회·필터·이동 경로를 확인한다. 실제 은행 지급·세금 신고·정산 잔액 변경을 검증을 위해 임의 실행하지 않는다.

## 검증

백엔드 테스트는 관리자 권한, 유료 원거래, TL 예약·중복·동시 요청, 세무 분류, 승인 버전, 지급 증빙, 원화·TL 합계, 취소 반환, 세금 납부 전표 연결을 검증한다. 브라우저 테스트는 실제 Hono 판매 API와 SQLite 시험 데이터로 매니저→스토어→원거래→매출 전표, 정산 예약→승인→지급 기록→세무 프로필·원화 전표 이동 및 모바일·오류 후 오래된 금액 제거를 검증한다. 시험 데이터 결과를 운영 지급 완료로 간주하지 않는다.
