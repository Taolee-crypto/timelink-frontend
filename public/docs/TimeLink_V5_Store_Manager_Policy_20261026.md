# TimeLink V5 스토어·영업 매니저 정책 기록

기준일: 2026년 10월 26일, 한국시간
기록 범위: 이번 대화에서 사용자가 정한 정책, 제안된 운영안, 추가 확정이 필요한 사항. 이 문서의 저장은 코드·운영 설정·원장 잔액에 반영됐다는 뜻이 아니다.

## 1. 사용자가 확정한 스토어 정책

상점주는 스토어에 무료로 가입한다. 가입 선물은 기존 42,500TL에 57,500TL을 더한 총 100,000TL이다. 기존 42,500TL이 이미 지급됐다면 추가 지급분은 57,500TL이며, 총액을 다시 지급해 중복 적립하지 않는다.

상점주는 가입 선물로 서비스를 이용하고, 이를 모두 소진하면 TL을 구매해 계속 이용한다. 영업 매니저와 파트너 DJ의 서비스비 배분은 그 유료 이용 단계부터 발생한다. 무료 가입 선물의 사용을 유료 이용료로 계산해 매니저·DJ에게 지급하지 않는다.

매장 서비스비의 50%는 영업 매니저와 파트너 DJ가 나누는 재원이다. 나머지 50%는 플랫폼 몫이다. 이 매장 서비스비에서 창작자에게 별도 몫을 추가 배분하지 않는다. 음원의 방송 사용에 대한 창작자·권리자 보상은 별도의 방송 보상 규칙으로 처리한다.

영업 매니저는 가입한 국가 내에서 독점 구역이나 섹터 없이 활동한다. 영업이 완료된 매장은 스토어 월드에 개별 매장 페이지를 갖고 해당 매니저 아래에 연결된다. 이미 연결된 담당 매니저의 변경은 상점주의 요청을 기준으로 처리하며, 이후 발생하는 거래부터 새 담당자에게 배분한다. 기존 거래의 배분 이력은 보존한다.

## 2. 사용자가 확정한 매장 소비 보너스

상점주는 타임링크 회원의 매장 소비에 대해 결제액의 1%를 보너스로 지급한다. 이 보너스는 즉시 사용 가능한 TL_P이다. 예를 들어 실제 결제액이 5,000원이면 보너스는 50원 상당, 즉 50TL_P이다.

위 예시의 보너스 산정은 1원당 1TL 기준이다. 이것이 모든 TL·TLC의 환전율과 모든 국가의 환율을 일괄 확정하는 것은 아니다. 즉시 사용 가능하다는 조건과 현금·TLC 교환 자격은 구분하며, 이 대화에서는 환전 조건을 새로 확정하지 않았다.

매장 소비 보너스는 기존 일반 활동 포인트와 별도로 출처를 기록한다. 매장 소비 활동을 일괄 TL_B로 처리하던 기준이 있다면, 이번에 지정한 결제액 1% 보너스에는 TL_P라는 새 지시를 우선 적용한다.

## 3. 아직 확정되지 않은 제안

| 항목 | 제안 | 확정 상태 |
| --- | --- | --- |
| 영업 매니저 가입비 | 초기 100,000원 | 제안, 사용자 최종 확정 전 |
| 매니저와 DJ의 내부 배분 | 매니저 25%, DJ 25%, 플랫폼 50% | 제안, 50% 공동 재원을 반반 나누는 안 |
| 소비 보너스 재원 | 상점주가 별도로 부담한 보너스 예치금에서 차감 | 구현 방식 제안, 예치·충전·정산 절차 미확정 |
| 가입 선물 계정 성격 | 방송 체험용으로 구분하고 고객 TL_P 발행 재원에서 제외 | 계정 유형·허용 범위 추가 확정 필요 |

가입비 10만 원은 교육·계약·영업 도구 제공을 감안한 초기 제안이다. 가입비 납부만으로 일정 수익이나 매장 배정을 보장하는 조건은 제안하지 않았다.

매니저 25%·DJ 25% 안을 적용하면 유료 서비스비 10,000TL에 대해 매니저 2,500TL, DJ 2,500TL, 플랫폼 5,000TL로 배분한다. 이 예시는 원화 현금 지급액을 확정하는 계산이 아니다.

## 4. 개발·원장 처리 기준

가입 선물, 유료 충전, 매장 소비 보너스의 출처를 V5 경제원장에서 구분한다. 같은 TL_P라도 고객의 직접 구매와 상점주 부담 소비 보너스는 원거래·부담자·재원이 다르므로 별도 식별값을 남긴다.

가입 선물로 유료 재원의 TL_P를 만들어 내거나, 선물 사용을 매니저·DJ의 유료 이용 수익으로 집계하지 않도록 해야 한다. 무료·유료 잔액이 섞인 결제에서는 실제 사용한 재원별로 배분 가능 금액을 계산한다.

가입 선물 추가 지급은 상점주·매장 자격과 기존 지급 이력을 확인하고 중복 지급을 방지한다. 개인회원이 여러 매장을 등록하는 경우 100,000TL을 회원당 지급할지 매장당 지급할지는 아직 정하지 않았다. 기존 선물 잔액을 사용한 계정의 추가 지급 방식도 확정이 필요하다.

소비 보너스는 결제 확인과 함께 1회 지급하고, 원거래 번호·매장·수취 회원·결제액·적용 보너스율·재원 차감·지급 TL_P를 연결한다. 취소·부분 환불·중복 요청·예치금 부족·이미 사용한 보너스의 정정 처리는 추가로 설계한다. 소수점 발생 시 반올림·절사 기준도 미확정이다.

매니저 가입에는 회원 인증, 가입계약서 확인, 직접 서명, 계약 내용과 서명 시각 보존, 입금 확인, 관리자 심사를 연결한다. 현재 구현의 테스트용 가상 입금 참조번호와 실제 은행 가상계좌는 구분한다. 실제 은행 연동 전에는 테스트 입금을 실제 현금 매출로 기록하지 않는다.

모든 가입비·보너스율·배분율·서비스 요금은 관리자가 수동으로 조정할 수 있게 설계한다. 변경 이유·승인자·정책 버전·효력 시각을 남기고, 과거 확정 거래의 비율을 소급해서 바꾸지 않는다. 초기에는 자동 최적화를 적용하지 않는다.

## 5. 다음 확정·구현 순서

1. 매니저 가입비와 공동 배분 재원 50%의 내부 비율을 최종 확정한다.
2. 가입 선물의 계정 유형, 사용 범위, 회원당·매장당 지급 기준을 정한다.
3. 매장 소비 보너스의 상점주 부담금 충전·차감 방식과 환불 규칙을 정한다.
4. 무료 가입과 추가 57,500TL 지급을 기존 42,500TL 지급 이력에 연결한다.
5. 무료 사용에는 서비스비 배분이 발생하지 않고 유료 사용부터 발생하는지 검증한다.
6. 5,000원 결제 시 50TL_P가 한 번만 지급되고 즉시 사용 가능한지 검증한다.

문서 상태: 정책 기록 완료. 가입비 10만 원·25/25/50 배분·보너스 예치금 방식은 확정안으로 오인하지 않도록 제안으로 표시했다.

## 6. 공통 회원 자격과 상점주 PoC·TLC 채굴 — 추가 확정

사용자 추가 지시: 상점주의 기여도를 PoC에 포함한다. 일반 이용자, 창작자, 상점주, 영업 매니저, DJ 등 모든 구성원은 공통 회원 가입을 통해 TLC 채굴에 참여할 기본 자격을 얻는다. 역할별로 별도의 회원 신분이나 채굴 계정을 만들지 않는다. 한 회원이 여러 역할을 수행하면 같은 회원의 PoC 기록에 역할별 검증 기여를 합산한다.

가입 시 기본 참여 자격을 얻는 것과 실제 채굴을 시작하는 것은 구분한다. 실제 채굴은 검증된 기여도가 운영자가 정한 누적 기준에 도달했을 때 개시한다. 가입만으로 TLC가 즉시 지급되거나 확정 수익이 발생하지 않는다. 개시 점수와 평가 기간의 구체적인 수치는 이번 대화에서 정하지 않았다.

기존 PoC 평가 체계를 확장하고 별도의 상점주 전용 점수 체계를 중복 운영하지 않는다. 점수·개시 기준·평가 기간·채굴 한도는 관리자가 수동으로 조정하고 정책 버전과 변경 이력을 기록한다.

### 다음 구현 과제

공통 회원의 기본 참여 자격 → 검증된 기여 누적 → 개시 기준 판정 → 채굴 가능량 산정 → 별도의 TLC 지급 원장이라는 단계를 연결한다. 회원 화면에는 현재 기여도, 적용 기준, 부족한 점수, 참여 상태를 표시한다. PoC 점수 계산만으로 TLC 잔액을 직접 올리지 않는다.

개시 최소점수, 누적 기간, 상점주 항목별 가중치, 역할별 한도와 실제 채굴량 산식은 미확정이다. 이번 추가 기록은 정책 확정 및 코드 현황 확인이며 운영 코드·원장 반영 완료를 의미하지 않는다.
