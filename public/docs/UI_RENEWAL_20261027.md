# TimeLink UI 리뉴얼 · 2026-10-27

사용자 승인 방향: TimeLink / New Asset / Broadcast / World Network의 네 대문. 선명한 사진, 절제된 서체, 충분한 여백, 작은 제목과 가벼운 버튼으로 정리한다. 기존 홈페이지의 사업 소개와 전용 플레이어 다운로드를 복원한다. 나머지 화면도 디자인의 현대화·세련미와 사용성을 함께 높인다.

## 실제 화면 연결

| 대문 | 목적지 | 이어지는 기존 기능 |
|---|---|---|
| TimeLink | `/timelink.html` | 사업 이야기 `/timelink-story.html`, 이용·가치 `/timelink-economy.html`, 비즈니스 `/b2b.html`, 다운로드 `/download.html` |
| New Asset | `/new-asset.html` | 음악 공유 `/shareplace.html`, 곡 상세 `/track.html`, 음악 등록 `/creator.html`, 기존 파일 관리 `/renewal/files.html` |
| Broadcast | `/radio.html` | 기존 TILO 방송과 청취 연결 유지 |
| World Network | `/world-network.html` | 스토어월드 `/cafe-world.html`, 카월드 `/my-car-world.html`, 나의 카페·차·DJ·영업 매니저 |

기존 대시보드와 공유플레이스, 창작, 지갑, 관리자 메뉴는 삭제하지 않고 계정·활동 메뉴에서 계속 제공한다. 첫 진입 화면만 TimeLink 사업 홈페이지로 변경한다. 뒤로가기, 검색, 개인 음악·방송 프레임 유지와 종료 정산을 보존한다.

## 화면과 사용성

공통 편집형 스타일은 기존 화면에도 연결한다. 지갑 계열의 어두운 배경을 기준으로 글자·간격·곡 카드·버튼·입력창·모달·표의 표현을 정리한다. 모바일 입력 글자는 16px, 주요 조작 영역은 44px를 기준으로 유지하고 키보드 초점과 줄어든 모션 설정을 지원한다. 오른쪽 광고 영역과 분할 여백은 복원하지 않는다.

내 정보는 프로필 편집과 별도로 작품·등록 내역, 파일, 음악, 카페, 차, 방송, 매니저, 지갑, 정산, 기여 현황의 기존 목적지 열 개를 연결한다. 등록된 것처럼 보이는 가상 개인 내역을 만들지 않는다.

New Asset의 공개 음악은 기존 공유 API 응답으로 표시하며 조회 실패 시 다시 시도할 수 있다. 영상·문서·이미지는 현재의 내 파일 관리로 연결한다. 이번 UI 변경이 영상·문서·이미지의 새 공개 거래·유료 재생 기능까지 완성했다는 뜻은 아니다.

## 유지하는 정책

TIME FREE 1시간은 실제 청취 3,600초이며 이용권 청취 중 TL 차감·보상 없이 기여만 반영한다. 기존 TL 지갑·기여·Daily Free 24개 상품·결제·권리·정산 로직은 바꾸지 않는다. 상품 페이지는 현재의 판매·테스트 상태를 그대로 안내한다.

## 검증과 복귀

기존 탐색·호스트·로그아웃·개인 재생·방송 유지 검사와 추가 브라우저 검사를 실행한다. 추가 검사는 네 입구, 다운로드·상품·개인 관리 연결, 실제 공유 API 계약에 따른 음악 표시·오류 복구, 기존 프로필 저장, PC·모바일 배치와 이미지 로드를 확인하고 스크린샷을 보관한다. 실제 운영 계정의 현금 결제나 음원 청취가 새로 검증됐다고 판정하지 않는다.

복귀는 본 PR의 커밋을 되돌리면 된다. 기존 URL·데이터·API가 유지되므로 데이터 마이그레이션이나 역변환은 없다.
