# TimeLink V5 기여도 관리자 화면 연결

2026-10-26 · 백엔드 PR #228 병합 후속 작업

## 연결 경로

관리자 콘솔 → 도구 → **V5 기여도·음악상품 관리** → `/contribution-policy.html`.
기존 `/reward-policy.html`에서도 새 화면으로 이동할 수 있다.

## 관리 범위

- 평가 기간, 최소 인정점수, 최소·최대 기여지수.
- 6개 영역의 가중치와 영역 만점 기준. 가중치 합계는 100%로 검증.
- 24개 활동의 활성 여부, 인정 기준수량, 단위당 점수, 기간 상한.
- 추천·제보 그룹 상한과 검증 근거 확인.
- 변경 사유를 포함한 수동 승인·저장 및 정책 변경 이력.
- 회원 번호에 따른 종합점수·기여등급·채굴 적용지수 조회.
- TL-1~TL-24의 시간·월 요금 초안·개별 채굴지수 조회.

## 적용 구분

이 화면은 신규 PoC 평가 정책을 관리한다. 구독 판매·결제, 일일 포함시간 실차감, 신규 TLC 지급을 활성화하는 화면이 아니다. 기존 보상 규칙의 PoC·채굴 설정과 신규 평가 정책을 구분한다. 백엔드에서 실제 검증 이벤트 수집이 연결된 활동만 평가에 반영한다.

## 오류와 동시 수정

- 서버 정책 버전을 함께 보내며, 다른 관리자가 먼저 수정하면 409 충돌을 표시하고 저장을 막는다.
- 충돌 시 입력내용을 보존한다. 운영자가 서버 값을 다시 불러오면 새 버전으로 전환한다.
- 네트워크·권한 오류로 다시 불러오기에 실패하면 이전 정책·상품·이력 표시를 비우고 저장을 비활성화한다.
- 표시 문자열은 DOM 텍스트로 처리한다. API 데이터의 HTML을 실행하지 않는다.
- 활동을 브라우저에서 생성하거나 점수를 직접 적립하는 HTTP 기능은 제공하지 않는다.

## 검증

`scripts/test-contribution-policy-ui.cjs`는 병합된 백엔드 정책 정의·검증기를 사용하는 API 응답으로 화면을 검증한다. 24개 활동·상품, 가중치 합계, 저장·변경 이력, 필터, 회원 조회, 충돌, 네트워크·인증 실패, 모바일 가로 넘침을 확인한다. 실제 운영 계정이나 결제·잔액은 변경하지 않는다.
