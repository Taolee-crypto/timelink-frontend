Traditional Access vs. TimeLink

Go beyond the limitations of unrestricted PDF downloads.

Traditional
Traditional Model
  • PDF delivery → download
  • Limited control over usage
  • Unrestricted copying, printing and screenshots
  • Product = file
  • No usage tracking
  • No usage-based settlement records
TimeLink
TimeLink Model
  • Register → encrypt → configure usage rights
  • Viewer → measure usage time → settle
  • Configure copying, printing and screenshot policies
  • Product = Document + Rights + Time
  • Track usage time by user
  • Audit Log + Version Control
