TL ECONOMICS / P2P EXCHANGE

TL ↔ TLC 교환풀

이용자가 보유한 TL과 TLC를 서로 교환하는 P2P 거래 공간입니다. TimeLink의 공식 TL → TLC 전환과 달리, 이곳은 이용자 간 기존 자산을 교환하는 에스크로 방식으로 설계됩니다.

V5 · 거래 기능 준비 중

내 TLC 지갑 연결 TON Network

TON 지갑을 연결하면 해당 지갑 주소를 이 교환풀에서 확인할 수 있습니다. 연결한 주소가 실제 TLC 보유 지갑인지 여부는 TLC Jetton 검증 API 연결 후 확인됩니다.

ⓘ PC 지갑 연결 방법
  1. Chrome에서 TimeLink 교환풀을 엽니다.
  2. TON 지갑 연결 버튼을 누릅니다.
  3. 연결 목록에서 MyTonWallet을 선택합니다.
  4. PC 지갑 앱으로 연결되는 선택지가 있으면 해당 앱에서 승인합니다.

QR코드만 표시된다면 데스크톱 앱 직접 연결이 지원되지 않을 수 있습니다. 이 경우 MyTonWallet 브라우저 확장 프로그램 연결을 확인하세요. 복구 문구나 비밀키는 입력하지 마세요.

연결된 TON 지갑이 없습니다.

연결 전

비밀키·시드 문구는 TimeLink에 입력하지 않습니다. 현재는 지갑 주소 표시만 지원하며, P2P 거래 승인이나 서버 계정 귀속은 아직 지원하지 않습니다.

교환 주문 작성

수량을 입력하면 주문 요약이 표시됩니다.
현재 주문 등록 및 자산 잠금은 실행되지 않습니다.

교환 주문장

아직 공개 가능한 실거래 주문이 없습니다.

검증된 V5 원장과 TON 입금 확인 기능을 연결한 후 실제 주문만 표시합니다.

거래 절차

① 주문 등록 → ② 거래 상대 매칭 → ③ TL 원장 잠금 및 TLC 온체인 입금 확인 → ④ 양측 자산 교환 → ⑤ 수수료 정산

운영사가 TLC를 받고 새로운 TL을 발행하는 공식 역환전은 제공하지 않습니다. P2P 교환에서는 기존 이용자의 TL만 이전합니다.

양측 거래 확인 · 안전 에스크로

거래가 매칭되면 양쪽의 제공 자산, 수령 자산, 주소, 수수료와 승인 상태가 함께 표시됩니다. 아래는 주문 입력을 반영하는 거래 조건 미리보기이며 실제 상대방이나 입금 확인 결과가 아닙니다.

이 화면은 실제 승인·잠금·인출을 수행하지 않습니다. 버튼은 서버 검증 및 TON 정산 기능이 완성될 때까지 비활성화됩니다. 양측의 수령 승인은 자산 수령 완료를 뜻하지 않고, 정산 전 조건 확인입니다.

안전한 거래를 위한 안내

수수료율과 거래 가능 자산, 최소 수량은 관리자 정책이 확정된 뒤 공개됩니다. TON 지갑 주소와 실제 TLC Jetton 자산 검증이 완료되기 전에는 거래를 시작할 수 없습니다. 외부 거래소의 TLC 상장 및 현금화 가능 여부는 보장되지 않습니다.
