# V5 개발 관리대장 실태 대조 — 2026-10-28

## 확인한 사실
- 관리대장: `public/v5-work-ledger.html`; 배포 작업 기록: `public/docs/development-releases.json`.
- 검증기 `scripts/check-v5-work-ledger.mjs`는 구문, 서버 우선 병합, 수동 수정 보존, 폐기 항목 제외, 사이드바 경로 일치를 검사한다. **실서비스 E2E 운영 검증을 대신하지 않는다.**
- 현재 지표 `progress`는 설계 20 / 구현 55 / 테스트 80 / 운영확인 100 가중 평균이다. 이는 실제 기능 완성률이 아니다. 운영확인 비율 `verified`와 구분한다.
- 폐기 필터는 DJ센터, 광고 수익, 영업파트너 및 삭제된 페이지를 집계에서 제외한다. 과거 기록은 유지한다.
- 릴리스 파일의 TIME FREE, 재생 안정화, 정산, 관리자 재무 등은 실제 운영 재검증 필요가 명시돼 있다. 구현 기록만으로 운영확인으로 승격하지 않는다.
- 서버 관리자가 수동 변경한 작업 상태는 자동 릴리스 병합이 덮어쓰지 않는다.

## 추가 확인 필요
1. 서버에 저장된 실제 관리대장 전체 작업 목록을 관리자 권한으로 조회하고 현재 브랜치 기록과 대조한다.
2. 각 공통관리·개별관리 기능의 화면, API, 권한, 실데이터, 결제·정산 E2E 근거를 수집한다.
3. 삭제 항목의 제목·ID·라우트 및 이전 정책 잔존 여부를 전수 확인한다.
4. 배포된 버전과 main 커밋이 일치하는지 확인한 뒤 운영확인 상태를 승인한다.
5. 검사 스크립트 및 실제 브라우저 회귀검사 결과를 PR 체크로 남긴다.

## 변경 원칙
근거 없는 상태 상향과 임의의 완료율 수정은 금지한다. 폐기 항목은 분모에서 제외하되 이력을 보존하고, 구현/테스트/운영확인을 분리한다.
